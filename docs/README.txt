THE JD SUITE — ABOUT PAGE STARTER

Angular: copy about.component.html into your About component template and about.component.css into its stylesheet. The CSS also works in an SCSS file. Keep your component configured to use these files.

The starter includes a header and footer. If your app already provides these globally, remove the header and footer from this template.

Navigation uses regular links to your site. In Angular, you can replace internal href links with routerLink if RouterLink is available in your component.

Preview: open about-preview.html with about.component.css in the same folder.

Colors are defined at the top of the CSS. Layout stacks on screens under 650px. No JavaScript or external dependencies are required.
